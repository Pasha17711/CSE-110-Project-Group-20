# Review Answers Screen

The Review Answers screen lets players review their answers after completing a heist.

## Features
- Displays questions in the order they were encountered.
- Shows whether each question was solved, solved with mistakes, or not solved.
- Displays incorrect attempts alongside the expected answers.
- Tracks repeated mistakes for each step.
- Supports Previous and Next navigation.
- Uses recorded step numbers to handle room re-entry.

## Files
- `EndScreen.ts` — Review modal and answer display.
- `EndScreen.test.ts` — Tests for the review functionality.
